# UpsilonAuth Website

The project website and developer guide for UpsilonAuth.

## Development

```sh
npm install
npm run dev
```

Use Node.js 20.9 or newer, then open `http://localhost:3000`.

## Verification

```sh
npm run lint
npm run build
npm run test:e2e
```

Playwright starts the production build on port 3100 for the end-to-end suite.
